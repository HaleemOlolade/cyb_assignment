# Fictional Student Dataset

## Description
A Python project containing 20 fictional university student records stored in a CSV file.

## Dataset fields
- Student ID
- Department
- Level
- Attendance Percentage
- Average Examination Score (out of 100)

## Files
- `student_dataset.py`: Python program that generates the dataset.
- `student_dataset.csv`: The completed dataset.
- `README.md`: Project documentation.

## How to run
Install Python 3, open a terminal in this folder, and run:

```bash
python student_dataset.py
```

The program creates `student_dataset.csv`.

**Note:** All records are fictional and are for educational use only.
